# tools/kit/examples.txt - what tools/make-kit.sh says about each example in Getting-Started.txt
# and whether it ships a native build.
#
#   [dir]           an examples/ drawer (examples/common and other drawers without .bas are skipped)
#   title=          shown name (default: Name= of the .bbp)
#   kind=           game | app | demo | console   (games and apps get a native build by default)
#   native=0|1      override the default
#   bbp=            the project's .bbp when there are several (default: the one that is not Bench/Trace)
#   about=          one line
#   keys=           a line of controls (repeat)
#
# An example with no entry here still goes into the kit: its title and line come from its .bbp,
# its kind from Startup= (Form: app, with a native build), and Getting-Started points to its
# README. Add an entry when a game or app lands on main.
